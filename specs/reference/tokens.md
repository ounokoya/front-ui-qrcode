# Tokens fournis par Frontend Mentor — front-ui-qrcode (QR code component)

> SDL-FM 1.5.0 Phase 1 (remise à niveau, étape B, lot 2 : refonte v2.0.0). Source : `style-guide.md`, `README.md` et images du starter actuel (2026-03-30). Seulement ce que FM fournit ; les valeurs mesurées viendront de l'analyse de la Phase 2 (`specs/visuel/`).

## Largeurs de maquette

Mobile 375 px, desktop 1440 px (images à l'échelle 1). FM demande une page correcte et conforme WCAG de 320 px aux grands écrans. Pas de maquette tablette.

## Couleurs

| Nom FM | Rôle observé | Valeur FM | Hex |
|---|---|---|---|
| White | Carte | `hsl(0, 0%, 100%)` | `#FFFFFF` |
| Slate 300 | Fond de page | `hsl(212, 45%, 89%)` | `#D6E2F0` |
| Slate 500 | Paragraphe | `hsl(216, 15%, 48%)` | `#68778D` |
| Slate 900 | Titre | `hsl(218, 44%, 22%)` | `#1F3251` |

| Contraste | Rapport | Remarque |
|---|---|---|
| Slate 500 sur White | 4,55:1 | paragraphe — juste au-dessus de 4,5 |
| Slate 900 sur White | 12,86:1 | titre |

Les contrastes du texte, des composants et de chaque icône sont vérifiés dans l'inventaire de la Phase 2, sur les couleurs mesurées dans les images.
